# Khualo Construction Website Documentation

Welcome to the documentation for the Khualo Construction Website, a modern marketing website for Khualo Multi Trading Services.

## Overview

This is a responsive React-based website built with TypeScript, Vite, and Tailwind CSS. It features multiple pages including Home, About, Services, and Contact, with SEO optimization and mobile-first design.

## Technologies Used

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Linting**: ESLint with TypeScript support

## Key Features

- Responsive design optimized for all devices
- SEO-friendly with meta tags and structured data
- Fast loading with Vite's optimized build
- Modern UI with smooth animations
- Contact forms and interactive elements
- Project gallery showcasing construction work
- Team section highlighting company expertise
