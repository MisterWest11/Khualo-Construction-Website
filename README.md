## Getting Started

1. Run `npm install`
2. Copy `.env.example` to `.env` and set your Web3Forms access key:

```bash
cp .env.example .env
# then edit .env and set VITE_WEB3FORMS_ACCESS_KEY
```

3. Run `npm run dev`
